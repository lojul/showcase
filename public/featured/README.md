# Featured project hero images

Add hero screenshots here and reference them in `lib/featuredProjects.ts`.

- Use filenames like `quick-poll-lightstreamer-hero.png` (or `.jpg`).
- Update each project's `image` in `featuredProjects.ts` from `/featured/placeholder-hero.svg` to `/featured/your-filename.png`.
- Recommended: 16:9 aspect ratio, ~1200×675px or larger; Next.js will optimize.
